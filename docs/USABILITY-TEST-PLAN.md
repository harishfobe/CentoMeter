# CentoMeter usability review script

Use `public/mobile-preview.html` with sample details only. Recruit 5–8 people across renters, buyers and property owners. These are proposed sessions, not completed research.

Tasks:
1. Find a two-bedroom rental within a budget. Switch to Buy and back, and explain which filters remain.
2. Move the map, save the search under a name, leave it and reopen it. Confirm the same area and criteria.
3. Save a property, add a private note, and organise it into a named list.
4. Open a property from the map, return to results, and confirm the search criteria remain.
5. Request a visit with a chosen date/time and contact method. Find it under Profile > Visits & enquiries, reschedule and cancel it. Explain whether the appointment is actually booked.
6. Start a listing, select a cover photo, move another photo earlier, save and exit. Start a second draft and resume the first from My sample listings.
7. Find homes near a sample landmark and explain whether the displayed distance represents travel time.

Record task completion, incorrect taps, requests for help and user expectations. Do not lead participants. Test 320/390/430px widths, the on-screen keyboard, enlarged text, keyboard navigation, browser Back, unavailable images and unavailable map tiles. Check fixed controls do not obscure focused inputs. Prioritise observed failures over adding more features.

Prototype boundaries: prices, availability, seller identities, distances and visit states are examples. No contact details are transmitted. A generic floor plan is clearly labelled and is not a property's actual plan. Share summary intentionally provides copyable text rather than a non-working public URL. No production integrations were added.
