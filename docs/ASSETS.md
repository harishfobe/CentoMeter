# Asset sources

All photographs are illustrative and are not associated with the fictional Indian properties.

- `public/apartment.jpg`: Francesca Tosolini, [Living room interior](https://unsplash.com/photos/living-room-interior-6japTIjUQoI), Unsplash.
- `public/land.jpg`: Dave Hoefler, [Landscape photography of green field](https://unsplash.com/photos/landscape-photography-of-green-field-Envk7kTMWTQ), Unsplash. This agricultural landscape stands in for the land-listing design; it does not depict a verified residential plot.
- `public/villa.jpg`: [Modern villa image in the Unsplash real-estate collection](https://unsplash.com/pt-br/s/fotografias/im%C3%B3veis), image identifier `photo-1580587771525-78b9dba3b914`.
- `public/interior.jpg`: Hannah Busing, [Photo of living room](https://unsplash.com/photos/photo-of-living-room-U-k6XLlml1I), Unsplash. Included as an alternative interior asset.

Images were resized from Unsplash image delivery URLs for this prototype. See the [Unsplash license](https://unsplash.com/license).

The map uses [OpenStreetMap](https://www.openstreetmap.org/copyright) tiles and retains visible contributor attribution. [Leaflet](https://leafletjs.com/reference.html) provides the browser map. [Lucide](https://lucide.dev/) provides interface icons. Inter provides locally bundled typography with system font fallbacks.

`public/centometer-logo.png`: supplied by the user as `IMG_2103.PNG` on 31 October 2026. The PNG is copied unchanged. The current header uses the requested HTML wordmark with an orange lowercase o; `public/centometer-favicon.svg` frames its orange pin using the same embedded PNG. Neither asset redraws the supplied artwork.

`public/fonts/InterVariable.woff2`: Inter variable font from the official rsms/inter repository (https://github.com/rsms/inter), downloaded 31 October 2026. Distributed under the SIL Open Font License; the bundled license is `public/fonts/Inter-LICENSE.txt`. No font-service request is needed at runtime.
